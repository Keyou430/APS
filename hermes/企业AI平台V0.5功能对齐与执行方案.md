## 第一部分：V0.5 功能对齐

### 一、产品定位

1. 名称：星纪年AI工作平台（原"云枢"，2026-08-07 更名）
2. 形态：企业级 AI 的**个人助理版**——先做单人使用，给老板用起来，再平移给部门负责人（权限不同）
3. 内核：以飞书/钉钉为生态底座（考勤、审批、日历等依托平台），本平台做**数据整合 + AI 决策 + 结果呈现**，像"套盒"一样
4. 原则：先解决一个人的问题（"一把手工程"），不做多人协同（2.0+）

### 二、V0.5 功能范围（郝博 8.10 定版）

#### 1. 驾驶舱（核心模块）

- **仪表盘**：关键经营数据展示；组件可添加、可分类（经营数据/人员统计等）、超过 5 个可翻页/换一批
- **待办事项**：

  - 日/周/月三级流转：当天未完成→自动进周待办→周未完成→月待办
  - 创建时间系统默认，截止时间可选可不选（选了按截止时间归类，没选按创建时间+2天流转）
  - 完成打勾进"已完成"；列表只显示条目，点进详情页
- **智能决策**（重点/精华）：

  - 定位：**AI 做方案，人做决策**（决策权在人）
  - 定时任务结果返回后，可审阅：认可/驳回
  - 类似"点赞/下载"交互；历史任务输出文档可查
- **日历**：简单版（类似待办，自我提醒，不提醒他人），尽量与飞书日历打通
- **重要文档 / 收藏文档 / 最近文档**：

  - 最近文档：定时任务结果、AI 生成文档自动收录（最近 10 条）
  - 重要文档：待办文档（还没处理完的），可点开处理
  - 收藏文档：好文档长期保存；可手动添加
  - 在线化优先（云文档/数据库），本地文档需上传
- **常用功能**：自定义卡片+按钮跳转（飞书/钉钉/企微入口），可无限往下加

#### 2. AI 办事（AI 服务）

- **知识库**：RAG 方案，可上传 Word/PDF/Excel，本地部署、数据归企业掌控
- **经验库**：优先级高于知识库（实操经验、决策案例、SOP）
- **记忆库**：平台内单独配置记忆功能（8.10 明确：很重要，当前 Hermes 还没配）
- **提问窗口**：底部常开（大众习惯），进入即见；找数据→提问→回答后可隐藏菜单栏
- 数据源接入：API/连接器/人工导出，开放接口支持 AI 自动调用

#### 3. 平台打通（V0.5 单人版）

- 飞书打通：数据获取、文档、日历、审批流程（用个人账号串组织账号，逻辑已跑通）
- 钉钉打通：数据获取
- 单人版权限：以飞书/钉钉自有权限对接数据

#### 4. V0.5 明确不做（边界）

| 不做 | 原因/去向 |
|-|-|
| 多人协同/协作 | 2.0+ 另立项 |
| 组织架构模块 | 个人版去掉，挂飞书链接即可 |
| 手机版 | 先做电脑版（横屏） |
| 本地文件夹扫描 | 网页端限制，需客户端，后续升级版再做 |
| 王总式固定化工作流 | 2.0 讨论，不在 V0.5 |
| 复杂定制功能 | 保持通用、简单 |

### 三、V0.5 当前状态（8.14 核对）

| 项 | 状态 |
|-|-|
| 后端：权限、飞书/钉钉打通 | ✅ 已实现 |
| 后端：基础对话（AI 问答） | ✅ 已实现（文字程度） |
| 知识库接入 | 👷 接入中（Hermes 已接系统） |
| 前端：驾驶舱 UI | ❌ 前端未上线（改版中，接口对接阶段） |
| 审批（流水线任务用户确认） | ❌ 未实现（"审批"= 任务结果确认，不是 OA 审批） |
| 定时任务 | ❌ 未实现（V0.5 最关键的缺口） |
| 记忆库 | ❌ 未配 |
| AI 结果呈现（驾驶舱结果框） | ❌ 未设计前端（2.0 建议内容） |
| 数据来源 | ⚠️ 未知：郝博要展示什么数据、怎么分析、怎么呈现未定 |

### 二、推进流程（本阶段起执行）

1. **每个阶段**：需求（进需求池）→ 写执行手册 → 执行开发
2. **执行差不多**：碰头讨论（腾讯会议），定下一阶段需求
3. **再写下一阶段执行手册**，如此循环
4. 团队开学后时间减少——靠群内进度同步 + AI 跟消息补位，阶段碰头对齐

### 三、协作规范

1. **代码**：GitHub 提交（洲瑚已有读权限，可查看进度）
2. **进度**：每个人做了什么，及时在群里说（不要等问）
3. **边界**：做不到的、有风险的，**提前说**，不要最后爆
4. **技术难点/需要支持**：随时提出来，不憋着
5. **阶段效果**：每个阶段结束时，能演示什么效果要明确

### 四、V0.5 目标（可验收的）

1. **给郝博一个能用的单人版驾驶舱**：登录 → 看仪表盘 → 记待办（日/周/月流转）→ AI 办事（知识库问答）
2. **飞书/钉钉数据能通**（个人版）
3. **AI 能对话执行基础任务**（如"帮我整理月报"，从飞书取数→生成→对话内返回）
4. **一个可演示的 V0.5 效果**：演示时讲清"我们现在有什么、和王总的区别、2.0 方向建议"
