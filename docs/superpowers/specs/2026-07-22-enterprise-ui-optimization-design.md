# 云枢企业智能平台 UI 优化设计

日期：2026-07-22

## 目标

- 将所有用户可见的 Hermes 品牌内容替换为“云枢企业智能平台”或短名“云枢”。
- 在不重构工作台业务结构的前提下，提升工作台和知识库的视觉层级、空间利用率和企业产品质感。
- 移除 Mock 运行时随机失败，保留可控延迟和真实服务错误展示能力。
- 将飞书/钉钉页面改为固定视口布局，仅允许工具栏和消息列表内部滚动。
- 将知识 AI 升级为可进入、可退出、可切换会话的完整对话界面。

## 非目标

- 不修改 backend。
- 不重命名 `hermes-*` localStorage key、API 字段、历史类型名或兼容标识。
- 不重做工作台网格、七个 Widget、拖拽缩放和布局持久化。
- 不引入真实 AI、SSE、WebSocket 或远端会话 API。
- 不扩大自动化测试覆盖；本轮以前端构建、lint、已有测试和用户手测为主。

## 品牌策略

新增集中式品牌配置，至少提供：

- 产品全名：`云枢企业智能平台`
- 产品短名：`云枢`
- 示例域名：`yunshu.example`

页面标题、登录页、导航、企业 Mock 数据、知识条目、AI 示例回答、示例邮箱和示例链接使用新品牌。内部存储 key 和 API 兼容字段保持不变，避免破坏已有本地数据和后端契约。

## 工作台

工作台保持当前 `WorkspacePage`、`DashboardGrid`、Widget 注册表和 Store 数据流不变，仅优化样式：

- 页面背景使用安静的中性层级，减少大面积纯白和强阴影。
- 标题区压缩垂直空间，突出页面标题、日期和布局状态。
- 工具栏与网格形成清晰的工作区边界。
- Widget 使用统一的细边框、低阴影、紧凑标题栏和稳定内边距。
- 调整文字层级、空白、状态色和按钮密度，不改变组件顺序或交互。
- 桌面端保持高信息密度；移动端维持现有单列/响应式行为。

## 知识库资源视图

知识库保留现有分类、搜索、筛选、上传、分页、批量操作和详情抽屉。样式调整包括：

- 页面标题、分类导航、工具栏和资源区形成清晰层级。
- AI 入口改为简洁的主操作区，显示“进入知识 AI”按钮和能力说明。
- 资源卡片降低装饰性，统一标题、摘要、标签和更新时间布局。
- 筛选控件在窄屏下自然换行，不产生水平溢出。
- 进入 AI 后资源状态保留，退出时恢复原搜索、分类、筛选和分页位置。

## 知识 AI 会话

### 页面状态

`KnowledgePage` 增加 `resources` 和 `chat` 两种视图状态。资源页点击 AI 入口切换到 `chat`；对话页点击“退出对话”返回 `resources`。

### 会话模型

扩展现有 `knowledgeStore`，在原持久化 key 中增加：

- `aiSessions`：会话集合
- `activeSessionId`：当前会话
- `knowledgeView`：`resources | chat`
- 新建、切换、重命名、删除会话和追加消息的 action

初始化提供 3 个示例会话。用户新建的会话和消息保存在本地，刷新后恢复。

### 交互规则

- 进入 AI 时优先选择最近会话；无会话时创建空白会话。
- 新会话首次提问后，根据问题前 20 个字符生成标题。
- 删除当前会话后选择下一条；无剩余会话时显示新建引导。
- 会话列表支持新建、切换、重命名和删除。
- 对话顶部显示会话标题和“退出对话”。
- 复用现有 `useAIQuery` 流式展示与引用数据，不引入真实流服务。
- 移动端会话列表使用可开关抽屉，保证消息区和输入区可用。

## 飞书与钉钉平台页

### 固定布局

- 页面高度固定为应用可用视口，不产生 document/window 滚动。
- 平台标题栏固定在顶部。
- iframe/内容区占据剩余空间，并保持自身尺寸稳定。
- 消息、最近访问和访问设置仅在边缘工具栏内部滚动。

### 边缘工具栏

采用已确认的方案 A：

- 默认收起为窄图标栏。
- 桌面端鼠标进入时临时展开，离开后自动收起。
- 提供固定按钮；固定后保持展开。
- 提供明确的手动展开/收起按钮，手动状态优先并持久化到平台状态。
- 访问设置、最近访问和通知使用分组或标签切换，避免同时占据大量宽度。
- 移动端不依赖 hover，通过按钮打开覆盖式工具面板。

飞书和钉钉继续复用 `PlatformPageLayout`，各自保存 URL、最近访问、通知和工具栏固定状态。

## Mock 策略

- 默认和实际运行时不再随机抛出 Mock 错误。
- `withMockRuntime` 和知识 AI 查询只执行延迟与正常数据返回。
- 现有 `errorRate`、`failuresRemaining` 等配置字段暂时保留为兼容 no-op，减少测试和调用方改动。
- 页面错误 UI 保留，用于未来真实 API 失败或显式异常。

## 可访问性与响应式

- 所有图标按钮提供 `aria-label` 和 tooltip/title。
- 边缘工具栏支持键盘聚焦、Enter/Space 展开和 Escape 收起。
- AI 会话列表使用语义化列表与当前项状态。
- 删除会话需要确认或可逆提示，避免误操作。
- 390px 宽度下不得产生水平滚动，输入框、按钮和长标题必须可用。
- 支持亮色与暗色主题，不增加单一品牌色占比。

## 主要文件边界

- 品牌：`src/config/brand.ts`、登录页、AppLayout、Mock generators、页面可见文案。
- 工作台：`WorkspacePage.module.css`、`components/dashboard/Dashboard.module.css`，必要时少量页面结构标签。
- 知识库：`KnowledgePage.tsx`、`KnowledgePage.module.css`、`components/knowledge/AIPanel.tsx`，新增会话视图组件。
- 会话状态：`stores/knowledgeStore.ts`、`hooks/useAIQuery.ts` 的最小适配。
- 平台：`PlatformPageLayout.tsx`、`PlatformPageLayout.module.css`、平台状态类型和 `uiStore`。
- Mock：`mock/runtime.ts`、知识 AI handler、可见 Mock 文案。

## 验证范围

- `npm run build`
- `npm run lint`
- 运行受改动影响的现有 Vitest；仅为会话 Store 增加少量状态测试（如现有测试必须更新）。
- 浏览器烟测：品牌替换、工作台样式、知识库进出 AI、会话切换、平台固定布局与工具栏展开。
- 最终视觉与交互验收由用户完成，不新增大规模 Playwright 测试。

## 验收标准

- 用户可见界面中不再出现 Hermes 字样。
- 工作台业务结构不变，视觉层级和信息密度更统一。
- Mock 正常浏览不会随机出现错误页或失败提示。
- 飞书/钉钉页面不产生 document 滚动，工具栏和消息区域内部可滚动。
- 平台工具栏支持悬停临时展开与手动固定/收起。
- 知识 AI 可进入、退出、新建、切换、重命名和删除会话，并在刷新后恢复。
- `chatStore.ts` 用户修改保持原样，backend 无改动。
