# 钉钉演示应用接入清单

## 目标

将“星纪年AI工作平台”作为钉钉企业内部机器人接入 Hermes。首期验收包含私聊、群内 `@`、连续会话、处理状态、完整 Markdown 周报和可选 AI Card。

## 在钉钉开放平台中完成

1. 创建企业内部应用，应用名称填写“星纪年AI工作平台”。
2. 添加“机器人”能力。
3. 消息接收模式选择 `Stream 模式`；首期不需要公网回调 URL。
4. 应用可见范围只勾选演示人员或演示群。
5. 发布应用版本，并确认演示账号能在钉钉中看到机器人。
6. 如需流式 AI Card，启用 AI Card 能力、创建包含 `content` 字段的模板并发布，记录模板 ID。
7. 如需读取用户发送的图片或文件，在权限管理中开启机器人消息文件下载相关权限。控制台名称可能随版本变化，以创建机器人和 AI Card 时的缺失权限提示为准。

## 首期权限边界

### 必须开启

- 企业内部应用的“机器人”能力。
- 机器人消息接收模式：`Stream 模式`。
- 应用版本发布，并把演示账号加入可见范围。
- 若控制台把机器人收发消息列为独立权限，开启对应的机器人消息接收与回复权限。

### 按需开启

- AI Card：需要流式卡片效果时开启，并提供已发布模板的 Template ID。
- 机器人消息文件下载：需要让 Hermes 读取用户发来的图片、PDF 或 DOCX 时开启。

### 首期不要开启

- 通讯录全量读取、审批、考勤、钉盘、文档编辑等业务权限。
- 任意用户开放访问。服务端默认使用 `DINGTALK_ALLOWED_USERS` 白名单，并保持群聊必须 `@` 机器人。

## 需要交付给部署的参数

- `DINGTALK_CLIENT_ID`：应用 Client ID / AppKey。
- `DINGTALK_CLIENT_SECRET`：应用 Client Secret / AppSecret。
- `DINGTALK_ALLOWED_USERS`：允许使用机器人的演示账号 UserId；多个值用英文逗号分隔。
- `DINGTALK_ALLOWED_CHATS`：可选，限制可使用的群会话 ID。
- `DINGTALK_CARD_TEMPLATE_ID`：可选，用于流式 AI Card。
- `DINGTALK_ROBOT_CODE`：可选；未填时默认使用 Client ID。
- `DINGTALK_HOME_CHANNEL`：可选，用于定时任务和智能提醒的默认会话。
- `DINGTALK_WEBHOOK_URL`：可选，仅用于无当前会话时的主动通知。

凭据只写入服务器 `deploy/.env`，不写入 Git、文档或对话记录。更安全的交付方式是由管理员直接写入该文件，然后只通知“已就绪”。

## 当前附件边界

固定版本 Hermes 的钉钉 session webhook 支持 Markdown 回复，但不支持直接回传本地文件。因此首期将完整周报作为 Markdown 正文交付，不会虚假显示“已发送附件”。文件下载或在线文档写入作为第二阶段工具接入。

## 首次账号配对

1. 管理员确认应用版本已发布，演示账号在应用可见范围内。
2. 演示账号打开机器人单聊并发送 `你好`。
3. 机器人返回一次性 pairing code。
4. 部署管理员执行 `docker exec hermes-platform-hermes-1 hermes pairing approve dingtalk <code>`。
5. 演示账号再次发送 `你好`，应收到“星纪年AI工作平台”身份回复。

配对授权保存在 Hermes 数据卷中，容器重建后仍保留。不要通过 `DINGTALK_ALLOW_ALL_USERS=true` 绕过配对。

## 完整演示流程

### 单聊

1. 发送 `你好`。
   预期：助手自称“星纪年AI工作平台的 AI 办事助手”，服务于云枢精密五金，并提及招聘、入职培训、考勤、人事制度和员工关系。
2. 发送 `帮我完成周报`。
   预期：先显示处理状态，随后直接返回完整《人力资源部周报》Markdown；未知人数和指标写“待补充”，不得先追问或虚构。
3. 发送 `把周报里的待协调事项提炼成给总经理的三条建议`。
   预期：沿用当前会话上下文，输出三条管理建议。
4. 可选发送一份 PDF 或 DOCX。
   预期：机器人可读取用户发来的文件；首期不会把生成结果伪装成本地附件回传。

### 群聊

1. 将机器人加入演示群。
2. 普通群消息不应触发回复。
3. 发送 `@星纪年AI工作平台 帮我完成周报`。
   预期：机器人回复，且不同群成员默认使用各自隔离的会话历史。

### AI Card

1. 在钉钉开放平台创建并发布 AI Card 模板，模板变量包含 `content`。
2. 将 Template ID 配置为 `DINGTALK_CARD_TEMPLATE_ID` 后重启 Hermes。
3. 重复 `帮我完成周报`，验收卡片创建、流式更新和完成状态。
